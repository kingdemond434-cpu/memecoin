# Compact actor facts for operator research

The existing accepted ACTOR_OBSERVATION path already calls actor_children.
Funding/launch children now project only their consumer contract instead of
copying raw source detail, narrative instructions or population control metadata.
An admitted UTF8 actor fact can expand under the operator ASCII JSON encoding;
unrelated Unicode detail could then exceed the existing128KiB operator limit.
Projection prevents that block and avoids duplicating raw detail in child evidence.

Funding keeps raw amount/unit and supplied wallet-history evidence unchanged;
launch/buy triggers keep observed wallet/token/type and event/availability clocks.
Canonical parent/result references remain the provenance path. Original actor
observations stay retained. Missing facts still fail the existing consumer gates;
required evidence is not truncated to fit. No new watches, presets, identities,
funding associations, fills or signer/provider calls are introduced.

Existing watch matching, actual processing-time arm clocks, typed chain keys,
first-trigger policy and global token deduplication remain in force. Plans remain
AWAITING_QUOTE_COST_SAFETY_AND_SELL_VALIDATION with real_fill=false. No price
excursion, quote eligibility, sell viability, edge or Phantom fill is inferred.

Existing retained children and receipts are not rewritten or backfilled. The
existing conflicting-observation-seal guard remains: regenerating an old identity
with a different body requires explicit reconciliation, never forced acceptance.
This fixes compact child projection only. Upstream coverage, reviewed paper
presets, production integration and executable after-cost evidence remain separate
acceptance requirements.
